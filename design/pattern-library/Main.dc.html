Display tracking stops at -.024em. Bricolage draws f with a crossbar reaching past the stem, and below about that the two crossbars in “different” merge into the i beside them. The site's hero runs a notch tighter still at -.022em because that one headline was measured; treat -.024em as the working limit and measure anything tighter against the actual words.

Mono is not decoration. Identifiers, timestamps, basis points and minor-unit amounts are monospaced everywhere, unrounded and unformatted — 2400 bps, not “24%”. If a person may have to read a value back to someone or paste it into a search box, it appears exactly as the API returned it.

Three defects to fix before any of this matters

The Admin declares font-family: Inter and ships no font file and no @font-face — on every machine without Inter installed it silently renders in the system UI font. --surface-soft is used three times and never declared. And four var() fallbacks name a colour that is not the token they fall back from: var(--line, #d9e2dd) against --line: #dce1da, var(--line, #eef2f0), and var(--danger, #b3564d) against --danger: #a23636.

Honest note about this document

These sheets pull both faces from Google Fonts, which the shipped site refuses to do — it vendors them, because vercel.json sets font-src 'self'. The canvas this is drawn on admits no other font host. The rule stands for the product; the drawing of it could not obey the rule.
