Controls

Every geometry below is the site's, not a new one: 12px radius and 13px 20px on buttons, 6px on state chips, 3px on callout borders. Containers lose their radii (sheet 01); controls keep theirs.

Buttons

Primary — the accord action

Green because on this product green means in accord, and approving is what produces the accord. Exactly .button.primary from the site — accent ground, paper text, 5.97:1.

Secondary — everything else

Save, create, navigate. Ordinary work is never green — if every button is the accord, none of them is.

Refusal — an extension

The one control here the site has no equivalent for, because a marketing page never asks anyone to refuse. It ships only beside an Approve, never alone.

Disabled

Always beside a stated reason, never on hover only. A disabled Approve with no explanation is the product failing at its one job.

Busy

The Admin's own button[aria-busy="true"], kept.

Focus

outline: 2px solid var(--accent); outline-offset: 3px — the site's exact rule. The Admin uses a 2px offset today; align it.
