## Publication evidence

- Run advertised commands against the stated source/package version. A scripted
  replay is labelled as such, not a fabricated Claude Code or Codex build session.
- Show the result, useful failure and boundary, with synthetic data. Explain
  local actor fixtures separately from deployment authentication.
- Include a downloadable brief or runnable example and one specific next step.
- Cite ledger ids and executable authorities. Competitor statements require
  current primary sources and a verification date.
- Record accountable editorial ownership and owner publication authority or
  explicit delegation. Do not claim human review when an agent performed it.
- Preserve failed attempts and manual interventions. Internal recipe execution
  does not prove external adoption or a general build success rate.
