# JTBD catalogue v1.1 normalization

## Goal and user-visible outcome
Resolve the catalogue's approval invariant without inflating coverage, give every desired job an explicit roadmap disposition, and preserve a reviewable record of every semantic decision.

## Current repository context
The desired catalogue is `docs/jtbd/catalog/jtbd.jsonl`; quality candidates are in `docs/jtbd/quality/findings.json`; coverage and roadmap are independent overlays generated by `scripts/jtbd-gate.js`. At the branch point, 280 L3 rows deny required approval and 503 roadmap rows have no milestone.

## Approaches considered
1. Flip all approval booleans: rejected because it overrides the records' explicit no-approval intent.
2. Downgrade every contradictory row to L2: chosen only after confirming all 280 are LOW/MEDIUM risk, explicitly say approval is not required, and L2's canonical definition permits recommendation/preparation without execution.
3. Hand-edit records and roadmap rows: rejected because it is unauditable and invites omissions; checked proposal/disposition files carry every decision.

## Milestones
1. Generate a correction proposal with old/new fields and semantic context.
2. Apply approved-by-rule corrections, move catalogue version/checksum, and enforce semantic validation.
3. Record a disposition for every proved quality finding and preserve supersession resolution.
4. Generate explicit clustered roadmap assignments for every desired job without changing coverage.
5. Record the reverse capability audit and public/private overlay boundary.
6. Run all requested gates and leave the PR open for human product review.

## Validation
`python docs/jtbd/tools/verify_catalog.py`; `node scripts/jtbd-gate.js`; `npm run repo:truth -- --check`; `npm run verify`; `npm run smoke`; `npm run gtm:check`; `npm run site:check`.

## Progress log

- 2026-08-21: 280 contradictions resolved by reviewed rule; catalogue checksum moved; every desired job assigned to a coherent roadmap slice; reverse audit and proved-finding dispositions recorded.
