# Prompt 04 — Evidence-based competitor benchmark

## Goal

Compare Accordo against named CRM/CDP/agentic products by equivalent JTBD/capability, not by marketing label.

## Method

1. Select relevant JTBDs/capabilities from `docs/jtbd/` and use the evidence-backed Accordo overlay for the target SHA.
2. Research current primary sources where possible: official documentation, release notes, API docs, security docs and hands-on product evidence.
3. Record date, edition/tier, source and confidence for every competitor claim.
4. Separate GA, beta/preview, paid add-on/partner, announced roadmap and unverified inference.
5. Compare functional depth, time-to-value, autonomy, evidence, governance, extensibility, analytics and TCO only where evidence permits.
6. Produce parity gaps, defensible differentiators, build-vs-integrate candidates and claims requiring hands-on validation.

No competitor score without dated evidence. Do not transfer a suite-level feature to every edition or module.
