Accordo

The framework coding agents use to build custom CRMs. Describe your commercial process to Claude Code or Codex; get a working CRM as reviewable code you own.

$ git clone https://github.com/khaoss85/agent-crm.git

Scaffolding via npm create accordo lands at the first public release.

What the framework does today

  • Deterministic workflows. Commercial policy is code, not a prompt — the same inputs produce the same decision, every run.
  • Human approval boundaries. Consequential decisions require a human actor by construction; an agent cannot make them on your behalf.
  • Audit and trace inside the transaction. Every mutation records who did what, under which policy version — explainable after the fact.
  • Declared, fail-closed packages. Domains are opt-in and removable; an undeclared dependency stops the app at startup, never mid-transaction.
