How to check us

Don't take the ledger's word for it.

# clone, install nothing, run everything
git clone {{brand.repository}}.git my-crm && cd my-crm
npm run verify        # {{measured.tests}} tests
npm run smoke         # the approval demo, asserted

# ask the framework what it thinks it is
npm run crm -- app inspect --json | jq '.limitations'

# rebuild this site and re-check every claim on it
npm run site:check

The third command is the one worth running. app inspect reports its own blind spots as machine-readable limitation codes — that it never opened the database, never contacted a provider, never read a secret, and can report no runtime or authorization state. A tool that lists what it cannot see is a tool you can reason about.

What has actually been measured

Two instruments, two different answers.

The build benchmark — can an agent turn a CRM brief into a working application — is designed, published and has not been run. No success rate exists, and any number you see quoted for this project was invented somewhere else.

A narrower instrument has run: a tool-selection panel asking whether a coding agent, given a plain business goal, picks the right framework command instead of assembling an answer by hand. Its protocol was frozen and fingerprinted before the first cell ran, every expected outcome was pre-registered in a commit that precedes every run, and the receipts are all committed — including the 52 planned cells that could not run because two of the three agent products were not installed, and one run that hit its turn cap. It contains no success rate by design: one measured arm is a pilot, not a comparison, and the record says so about itself. It measures agent behaviour on this repository, never framework capability, and it licenses no ranking of any product.

That is the discipline the rest of this page rests on: the scoreboard is built and published before the first result, the parts that hurt are committed next to the parts that flatter, and a figure this project has not measured does not appear here.
